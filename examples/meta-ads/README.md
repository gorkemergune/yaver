# Örnek Meta Ads Manager dışa aktarımları (uydurma)

"Örnek Kafe" adlı hayali bir işletmenin iki haftalık kampanya raporu. Sayılar uydurmadır.

- `ornek-kafe-2026-11-02_08.csv`: İngilizce arayüzden dışa aktarım (`,` ayırıcı, nokta ondalık).
- `ornek-kafe-2026-11-09_15.csv`: Türkçe arayüz / Excel (`;` ayırıcı, `1.500,00`), başta
  adı boş toplam satırı var (atlanır).

Denemek için önce ilk haftayı, sonra ikinciyi sohbete at: Metrics ikincisini ilk haftayla
karşılaştırır, özet + 3 öneriyi defterine yazar.

Kendi dosyan: Ads Manager → Kampanyalar → tarih aralığını seç → **Dışa aktar** →
**Tablo verilerini dışa aktar** → CSV. Sütunlardan en az kampanya (ya da reklam seti /
reklam) adı ve harcanan tutar olmalı; sonuç, gösterim, bağlantı tıklamaları, TO (CTR),
TBM (CPC) ve sonuç başına maliyet varsa onlar da okunur. Tablonun ekran görüntüsü de olur.
